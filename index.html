Production-ready, security-hardened Kubernetes Helm Charts and DevOps utilities.

GitHub Repository 📄 index.yaml 📦 Releases

⚡ Quick Start

Add this Helm repository to your local CLI to search and install charts:

helm repo add devtools https://devhaucx.github.io/devtools
helm repo update
helm search repo devtools

🐳 OCI Registry (GHCR)

You can also install charts directly without adding a repository via OCI:

helm install my-agent oci://ghcr.io/devhaucx/devtools/azure-agent --version 0.1.0
helm install my-cronjob oci://ghcr.io/devhaucx/devtools/cronjob --version 0.1.1
