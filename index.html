DevTools Helm Charts

Production-ready, security-hardened Kubernetes Helm Charts and DevOps utilities.

GitHub Repository 📄 index.yaml 📦 Releases

⚡ Quick Start

Add this Helm repository to your local CLI to search and install charts:

helm repo add devtools https://devhaucx.github.io/devtools
helm repo update
helm search repo devtools

📦 Available Charts

azure-agent

v0.1.0

Self-hosted Azure DevOps / TFS Agent on Kubernetes with Docker-in-Docker (DinD) sidecar. Supports container image builds, helm deployments, and kubectl commands directly from pipelines. 

helm install my-agent devtools/azure-agent \
  --namespace devops --create-namespace
App Version: v3 Documentation →

cronjob

v0.1.0

Production-ready Kubernetes CronJobs chart with zero-stuck auto-cleanup (TTL: 0, GracePeriod: 0). Centralized defaults, non-privileged security contexts, and safe secret injection. 

helm install my-cronjob devtools/cronjob \
  --namespace devops --create-namespace
App Version: 1.0.0 Documentation →

🐳 OCI Registry (GHCR)

You can also install charts directly without adding a repository via OCI:

helm install my-agent oci://ghcr.io/devhaucx/devtools/azure-agent --version 0.1.0
helm install my-cronjob oci://ghcr.io/devhaucx/devtools/cronjob --version 0.1.0
